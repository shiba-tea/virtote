# 買い物メモアプリ「Virtote」

HTML/CSS/JavaScript

制作期間：2026年10月～

自主製作

制作目的：

　JavaScript学習の一環として、LocalStorageを活用したWebアプリケーションの制作に取り組んだ。

　日常の買い物の場面で利用されることを想定し、アプリのダウンロードを必要とせず、ブラウザから手軽に利用できることを目指した。

機能：

 ・品目を入力し、データの追加・削除・編集を行う
 
工夫した点：

　・初めて利用する人でも操作方法をイメージしやすいよう、サンプルのリストや入力エリアの初期値を用意した。

　・ヘルプ画面へのリンクをほかのボタンと色を変えて差別化し、迷わないUIを目指した。
 
今後の改修予定：

　・並べ替え機能の追加
